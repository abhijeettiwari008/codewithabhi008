## 🚀 Getting Started

### Prerequisites
- GCC or Clang compiler
- Linux/Mac/Windows with WSL

### Compile and Run

```bash
# Navigate to a program directory
cd basic/

# Compile
gcc -o hello_world hello_world.c

# Run
./hello_world
```
